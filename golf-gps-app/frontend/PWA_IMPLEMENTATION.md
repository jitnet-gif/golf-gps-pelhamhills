# Golf GPS PWA Implementation

Comprehensive React + Vite Progressive Web App for real-time golf course GPS tracking and scorecard management.

## Architecture Overview

### Core Technologies
- **React 18** - UI framework
- **Vite 5** - Fast build tool with PWA plugin
- **Tailwind CSS** - Styling framework
- **Zustand** - Lightweight state management
- **Dexie** - IndexedDB wrapper for offline data
- **Leaflet + react-leaflet** - Interactive mapping
- **Axios** - API client with error handling

### PWA Features
- **Offline-First** - Full functionality without network
- **Service Worker** - Intelligent caching strategies
- **IndexedDB Storage** - Persistent local data
- **Installable** - Add to home screen on mobile
- **Real-time GPS** - Kalman-filtered position tracking
- **Tile Caching** - Satellite map tiles cached locally

## Key Components

### HoleMap (Map Display)
Displays interactive satellite map with:
- **Hole Pins** - Red markers for each hole (1-18)
- **Current Location** - Blue dot with accuracy circle (Kalman-filtered)
- **Tile Layer** - R2 bucket tiles (cache-first strategy)
- **Leaflet Integration** - Full map controls + click-to-select holes

```tsx
<HoleMap
  courseId="course-1"
  holes={holes}  // { holeNumber, latitude, longitude, par }
  zoom={16}
  onHoleClick={(holeNum) => handleSelectHole(holeNum)}
/>
```

### DistanceIndicator (Real-time Yardage)
Shows distance and bearing to selected pin:
- **Haversine Formula** - Accurate lat/lng distance calculation
- **Bearing Calculation** - Compass direction (N, NE, E, etc.)
- **Accuracy Indicator** - GPS uncertainty in meters
- **Visual Compass** - Rotating needle showing true direction

```tsx
<DistanceIndicator
  pin={{ latitude: 40.0, longitude: -74.0, holeNumber: 1 }}
/>
```

### ScoreCard (Score Entry)
Full 18-hole scorecard with:
- **Expandable Holes** - Click to enter score (1-13 range)
- **Running Total** - Real-time score aggregation
- **Progress Tracking** - Holes completed / 18
- **Compact Mode** - Sidebar preview

### CourseSelector (Course Picker)
Dropdown or full screen course selection:
- Fetch from `/api/courses`
- Fallback to demo courses offline
- Select to create new round

## Hooks Reference

### useGPS
Real-time GPS position tracking with Kalman smoothing.

```ts
const { isTracking, error, startTracking, stopTracking } = useGPS({
  enableHighAccuracy: true,
  timeout: 10000,
  maximumAge: 0,
});
```

**Kalman Filter**: Combines GPS measurements with process noise to produce smooth lat/lng estimates. Measurement noise derived from `GeolocationPosition.coords.accuracy`.

### useMapTiles
R2 bucket tile URL generation and offline caching.

```ts
const { getTileUrl, checkTilesInCache, cacheTilesForCourse } = useMapTiles({
  courseId: "course-1",
  r2BucketUrl: "https://tiles.example.com",
});

// Generate tile URL
const url = getTileUrl(z, x, y);  // https://tiles.example.com/tiles/course-1/16/x/y.png

// Cache tiles for offline
await cacheTilesForCourse(tileUrls);
```

### useScorecard
Round and score management with IndexedDB + sync queue.

```ts
const { currentRound, createRound, saveScore, getPendingSyncs } = useScorecard();

// Create round
const round = await createRound("course-1", 18);

// Save score
await saveScore(1, 4);  // Hole 1 = Score 4

// Get pending syncs
const pending = await getPendingSyncs();
```

### useOfflineMode
Network status monitoring and offline capability detection.

```ts
const {
  isOnline,
  hasGeolocation,
  hasServiceWorker,
  hasIndexedDB,
  syncWithServer,
} = useOfflineMode();

// Attempt sync
const success = await syncWithServer();  // Tries /api/health
```

## State Management (Zustand)

Global state in `appStore.ts`:

```ts
const store = useAppStore();

// Current round and scores
store.currentRound;    // { id, courseId, date, holes[] }
store.scores;          // Map<holeNumber, score>

// GPS position
store.gpsPosition;     // { latitude, longitude, accuracy, timestamp }

// Sync status
store.syncStatus;      // 'idle' | 'syncing' | 'error'
store.isOnline;        // boolean

// UI state
store.uiState.selectedHole;      // number | null
store.uiState.showScoreSheet;    // boolean
store.uiState.showSettings;      // boolean

// Actions
store.setScore(holeNumber, score);
store.setGPSPosition(position);
store.setSyncStatus('syncing');
store.resetRound();
```

## Database Schema (Dexie)

IndexedDB tables for offline data:

```ts
// Active rounds
db.rounds.put({
  id: "course-1-1725360000",
  courseId: "course-1",
  date: "2024-09-06T15:00:00Z",
  holes: [
    { holeNumber: 1, score: 4, timestamp: "2024-09-06T15:10:00Z" },
    { holeNumber: 2, score: 3 },
  ]
});

// Score records
db.scores.add({
  roundId: "course-1-1725360000",
  hole: 1,
  score: 4,
  timestamp: "2024-09-06T15:10:00Z"
});

// Sync queue (offline changes)
db.syncQueue.add({
  type: "score",  // or 'round', 'tile-meta'
  payload: { roundId, hole, score },
  timestamp: "2024-09-06T15:10:00Z",
  attempts: 0
});

// Cached tile metadata
db.tileMeta.add({
  courseId: "course-1",
  tiles: ["https://tiles.../z/x/y.png", ...],
  lastUpdated: "2024-09-06T15:00:00Z"
});
```

## PWA Configuration

### Service Worker (vite-plugin-pwa)

Generated automatically by Vite PWA plugin. Caching strategies:

**Tile Cache (cache-first)**:
- All `.png`, `.jpg` images → check cache first
- Max 500 entries, 7-day expiration
- Includes R2 cross-origin responses (status 0)

**API Cache (network-first)**:
- `/api/*` endpoints → try network first
- 5-minute cache if network fails
- 3-second timeout to fallback to cache

### Manifest (public/manifest.json)

- App name, icons, theme colors
- Start URL, display mode (standalone)
- Shortcuts (New Round)
- Share target for Web Share API

## API Integration

### Expected Backend Endpoints

```
GET  /api/health                      # Health check
GET  /api/courses                     # List courses
GET  /api/courses/:id                 # Get course details
GET  /api/courses/:id/holes           # Get hole GPS coordinates + pars
POST /api/games                       # Create new round
POST /api/scores                      # Save score
PUT  /api/scores/:id                  # Update score
```

Response format (example):

```json

  "holes": [{

    "latitude": 40.000,
    "longitude": -74.000,
    "par": 4,
    "handicap": 5,
    "length": 375
  }]
}
```

## Offline Sync Strategy

1. **User enters score** → Save to IndexedDB immediately (optimistic update)
2. **App goes offline** → Sync queue accumulates changes
3. **Network returns** → Pull pending syncs from `db.syncQueue`
4. **Batch sync** → POST changes to `/api/sync` endpoint
5. **Retry logic** → Max 3 attempts per item, exponential backoff
6. **Cleanup** → Remove from queue on success, increment retry count on failure

## Performance Considerations

### Bundle Size
- React: ~42KB (gzipped)
- Leaflet: ~40KB
- Zustand: ~3KB
- Dexie: ~30KB
- **Total**: ~150KB gzipped

### Runtime
- **Map rendering**: 60fps with Leaflet canvas mode
- **GPS updates**: 10Hz (every 100ms) with Kalman smoothing
- **Score entry**: <100ms IndexedDB write + UI update

### Caching
- **Tile pyramid** (z16-18): ~500 tiles = ~10MB disk
- **API responses**: 5-minute cache (50 entries max)
- **Service Worker cache**: ~50MB total quota

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Map blank | Check Leaflet CSS import, verify L.Icon.Default paths |
| No GPS signal | Enable location permission, wait 30s for Kalman warmup |
| Tiles not loading | Verify R2 bucket URL, check CORS headers, enable cache |
| Scores not syncing | Check network status, verify API endpoint, inspect IndexedDB |
| Service Worker not registering | Check vite.config PWA plugin config, clear browser cache |
