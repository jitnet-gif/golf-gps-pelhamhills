# Build and Deployment Scripts

This directory contains utility scripts for building and deploying the golf GPS app.

## Available Scripts

Add build automation scripts here for:
- Database migrations
- Seed data import
- Asset optimization
- Pre-deployment checks

Example:
- `init-db.ts` - Initialize database schema
- `seed-courses.ts` - Load golf course data
- `optimize-images.ts` - Compress and optimize course photos
