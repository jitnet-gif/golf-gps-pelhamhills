문제점 진단

1

Cancel 의미가 불명확

현재 Cancel은 예약 취소가 아니라 상태를 Reserved로 되돌립니다. 운영자는 실제 취소로 오해할 수 있습니다.

2

Save와 결제가 섞임

저장은 예약 정보 변경이고, 결제 완료는 별도 액션입니다. 지금은 Save가 Paid 처리까지 수행합니다.

3

플레이어 단위 제어 부족

한 명만 삭제, 체크인, 결제, no-show 처리하는 흐름이 필요합니다. 현재는 예약 전체 상태 중심입니다.

4

그리드 위치 계산 취약

예약 블록 위치가 고정 픽셀 기반이라 화면 크기나 컬럼 변화에 약합니다. grid 좌표 기반으로 바꿔야 합니다.

5

운영 데이터 유지 부족

새로고침 후 샘플 데이터로 돌아갑니다. 예약, 결제, 취소, 플레이어 변경을 저장해야 합니다.

6

시간표 생성 로직 없음

운영 시작시간, 간격, 홀 수, block time, dynamic rate가 설정 기반으로 생성되어야 합니다.
