# 예약 API 배포용 최소 의존성 (backend/Dockerfile 이 이 파일만 설치한다).
#
# `requirements.txt` 는 개발 머신용이다 — psycopg2, pgvector, boto3, anthropic,
# jupyter 까지 들어 있어 이미지가 수백 MB 로 불어나고, 정작 예약 API 는 그 중
# 무엇도 쓰지 않는다.
#
# 이 목록으로 뜨는 라우터 (`backend/main.py` 의 include_route_module 순서대로):
#   - tee_sheet  : 티 시트/예약    (fastapi, pydantic + Supabase REST 는 httpx)
#   - simulator  : 실내 시뮬레이터 (표준 라이브러리 smtplib)
#   - retail     : 프로 샵 판매    (JSON 저장소)
#   - voice      : 음성 예약       (httpx)
#
# 뜨지 않는 라우터: chat / agents / onboarding. 셋 다 저장소에 없는 모듈을
# 임포트하므로 로컬에서도 이미 실패한다. `include_route_module` 이
# 예외를 잡아 로그만 남기고 넘어가므로 서버는 정상 기동한다 — **의도된 동작**이다.

fastapi==0.109.2
uvicorn[standard]==0.27.0
pydantic==2.6.3
pydantic-settings==2.2.1
python-dotenv==1.0.0
httpx==0.25.2
